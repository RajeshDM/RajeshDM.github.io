GABAR: Three Design Choices

Action-Centric Graph

Objects, predicates, and
actions as graph nodes

Actions are explicit nodes connected to objects by edges encoding parameter roles and precondition satisfaction.

Action Ranking

Rank applicable actions
in a given state

Only locally consistent rankings needed, not globally consistent value functions. More robust to size increases.

Conditional Decoding

GRU-based sequential
parameter selection

Each parameter choice conditioned on the action schema and all previously selected parameters.
