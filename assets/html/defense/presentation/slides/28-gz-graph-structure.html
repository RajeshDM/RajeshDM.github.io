Belief Graph Structure

Encoding uncertainty in both nodes and edges

Example: Warehouse Belief Graph
Three Node Types
O
Object
A
Attribute
●
Action

Attribute nodes are created only when belief ≥ τ. Graph topology encodes what the agent believes is plausible.

Three Edge Types
Attribute ↔ Object
Action ↔ Object
Attribute ↔ Action

Edge weights carry belief probability. Thicker edge = stronger belief.

Why This Matters

Graph size scales with the problem — more objects just means more nodes. Same GNN works for any instance size.
