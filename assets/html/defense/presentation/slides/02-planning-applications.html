Sequential Decision Making in the Real World

Path Finding

Navigate from start to goal while avoiding obstacles — find the shortest collision-free route.

Plan = sequence of moves

Robot Manipulation

Pick, place, and rearrange objects in a household — coordinate gripper actions across multiple items.

Plan = pick/place actions

UAV Navigation

Fly through dynamic environments, avoiding obstacles and adapting to wind — reach target locations safely.

Plan = flight waypoints

In each case, the agent needs a sequence of actions from a start state to a goal state — this is the planning problem. But how do we actually find these plans?
